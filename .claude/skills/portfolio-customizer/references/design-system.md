# Design system

Source of truth: `src/styles/tokens.css` (light in `:root`, dark in `[data-theme='dark']`). Change tokens, not component CSS. A live, always-in-sync sample page is generated by `node scripts/make-design-system.mjs` into `public/design-system/index.html`.

## Tokens

- **Palette:** `--navy` (ink), `--cream` (page), `--white` (card), `--paper`, `--orange` (accent), `--orange-hover`, `--orange-ink` (accessible orange text), `--muted`, `--success`, `--error`, `--verified`. Dark theme redefines the same names, so components flip automatically.
- **Surfaces:** `--line`, `--line-strong`, `--tint`, `--tint-strong`, `--glass`, `--plate` (always light, for logos), `--panel-dark`.
- **Type:** Poppins. `--fs-display`, `--fs-h2`, `--fs-h3`, `--fs-body`, `--fs-eyebrow`, `--fs-nav`; `--lh-*`; `--ls-display`, `--ls-eyebrow`.
- **Layout:** `--container-x`, `--section-pad-y`, `--rail-w` (312px from 1100px), `--panel-x`.
- **Shape:** `--radius-card` 24px, `--radius-pill`, `--radius-circle`.
- **Shadow:** `--shadow-soft`, `--shadow-card`, `--shadow-btn`.
- **Motion:** `--ease-out`, `--ease-spring`, `--dur-fast` 180ms, `--dur-med` 320ms, `--dur-slow` 600ms.

Rebranding recipe: change `--orange`, `--orange-hover`, `--orange-ink` (keep text contrast at 4.5:1 or better on cream and white), then `--navy`/`--cream` pair, then mirror in the dark block. Brand-mark colors (tools, apps) stay in data files, not tokens.
